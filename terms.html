Beta scope and updates

Launcher 0.5.0 and integrated Client 0.1.0 are Public Beta. The integrated Client supports Minecraft Java 26.1.2 and 26.3, has 40 local modules, and is optional per compatible instance. Vanilla and normal Fabric remain usable with Client OFF. Client payloads are supplied through Launcher updates and applied before the next opted-in instance launch. Disabled instances stay disabled.

Availability for this release: 0.5.0 uses manual installation from its tagged prerelease. Existing 0.4.0 users remain on Stable 0.4.0. Automatic beta updates are not currently promised; future installed Launcher packages can supply newer Client payloads.

Client install/update/repair/disable/removal is designed to preserve worlds, other mods, settings, presets and Waypoints. Back up important worlds and data. No uninterrupted service, perpetual support, universal server/mod/shader/resource pack compatibility, or measured performance improvement is promised. Final human acceptance of physical Right Shift, complete HUD Studio/preset workflows, world-space Waypoints, material-colored Vanilla Armor and Vanilla Hunger Preview remains open and is disclosed in the release notes.

Privacy

Configuration, layouts, presets and Waypoints are stored locally. The Client adds no telemetry. Optional Discord Rich Presence is OFF by default. When ON, local Discord IPC provides generic main-menu/singleplayer/multiplayer activity, start time, optional Minecraft version and configured Vesper artwork. The presence payload excludes world/server names, addresses, coordinates, account identifiers and Waypoints. Discord controls activity visibility. Authentication, provisioning, optional mod downloads and release checks contact their upstream providers, which receive ordinary request metadata under their own policies. See the website privacy page for the specific service categories.
