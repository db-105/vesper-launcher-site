# Vesper Launcher Website

Official public website for Vesper Launcher, powered by Kognitiv Systems.

## v3.1 polish

- irregular animated starfield made visible above the background layer
- seamless, slower feature ticker with two complete tracks and hover-to-pause
- privacy title centered to the viewport
- dedicated Kognitiv Systems closing section using the official company logo
- independent download lanes use `db-105/vesper-launcher-releases`: Stable 0.4.0 resolves `/releases/latest`, manual Public Beta 0.5.0 resolves `/releases/tags/v0.5.0`
- each lane requires a published release with its exact tag, prerelease flag, asset names, sizes, SHA-256 digests and official URLs; incomplete/unavailable/replaced assets disable only that lane
- Beta remains disabled while its release is a draft. The Stable updater endpoint, signing key and release assets stay unchanged; no automatic beta update is promised
- the owner authorized publication of the prepared website after the manual v0.5.0 prerelease became public; the existing GitHub Pages repository and design are retained

Vesper is an independent project and is not affiliated with, endorsed by, or sponsored by Mojang Studios or Microsoft.
