WINDOWS DESKTOP LAUNCHER

A calmer launcher. A cleaner experience.

Vesper Launcher is an independent Windows desktop launcher for Minecraft Java Edition. It is designed around simple version management, isolated game directories, secure Microsoft authentication, and a clean dark interface.

Windows Public Client Microsoft Device Login No cracked login
01

What Vesper does

Version management

Fetches official Mojang release information and manages selected Minecraft Java Edition versions.

Verified game files

Downloads required files, verifies them and repairs damaged files when necessary.

Isolated instances

Keeps Vesper game data separate from the official launcher installation and other instances.

Java detection

Detects a compatible local Java installation and uses configured memory settings for launch.

02

Authentication & security

Vesper uses Microsoft's public-client device authorization flow. It never asks for, receives, or stores a Microsoft account password.

  • Microsoft scopes are limited to XboxLive.signin and offline_access.
  • No Microsoft Graph permissions are requested.
  • No client secret is embedded in the desktop application.
  • Refresh credentials are stored using Windows Credential Manager.
  • Access tokens are kept in application memory and are not published or collected.
  • Vesper requires valid Microsoft/Minecraft authentication and has no offline/cracked account bypass.
03

Project status

Vesper is currently in development and undergoing Minecraft Game Services application review. The launcher is not a Minecraft replacement and does not redistribute the Minecraft game.
