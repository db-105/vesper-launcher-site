01 / THE LAUNCHER

Less launcher.
More Minecraft.

Everything Vesper does is built around one idea: the launcher should solve problems before you notice them.

01

RUNTIME

Java that manages itself.

Vesper detects the Java version a Minecraft release actually needs. If it is missing, Vesper can prepare an isolated compatible runtime without changing your global PATH or JAVA_HOME.

02 / ORIGIN

It started with one launcher that didn't exist yet.

Vesper began in 2026 as a personal project by Dion: build the Minecraft launcher he actually wanted to use, then keep pushing until it felt like a real product.

The name Vesper comes from evening — the point where daylight gives way to the night. That became the visual language too: winter skies, cold light, quiet interfaces, and a launcher that feels calm instead of crowded.

01PrototypeA winter-themed launcher concept becomes a working Tauri desktop app.
02Real launchMicrosoft authentication, Mojang files and Minecraft launch reach production acceptance.
03Beyond vanillaJava automation, migration and secure updating lay the foundation for the Vesper Client.

“Vesper should feel like the moment before the game starts — quiet, cold, and ready.”

— AXON STUDIO
