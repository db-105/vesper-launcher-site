Privacy Policy

Last updated: September 2026

Overview

Vesper Launcher is a Windows desktop application for Minecraft Java Edition. Vesper is designed to minimize the collection of personal information.

Microsoft authentication

Vesper uses Microsoft's OAuth device authorization flow. Authentication is handled by Microsoft. Vesper never receives or stores the user's Microsoft password.

The application requests only the scopes required for Xbox/Minecraft authentication: XboxLive.signin and offline_access. Vesper does not request Microsoft Graph permissions.

Credentials and tokens

Refresh credentials are stored locally using Windows Credential Manager. Access tokens are held in application memory for the time required to authenticate with the relevant services. Vesper does not intentionally transmit authentication tokens to AXON Studio or any custom analytics server.

Local game data

Vesper stores launcher configuration, Minecraft files, logs, version metadata and instance data locally on the user's device. These files are necessary for launcher functionality and troubleshooting.

Account requirements

Vesper requires legitimate Microsoft/Minecraft authentication. It does not provide an offline, cracked, or authentication-bypass mode.

Third-party services

Vesper communicates with services operated by Microsoft, Xbox and Mojang/Minecraft where required for authentication, game metadata and legitimate game access. Those services have their own privacy policies.
