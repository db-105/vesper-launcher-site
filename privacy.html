Privacy Policy

Vesper Launcher 0.5.0 Public Beta · 11 October 2026

Overview

Vesper Launcher is a Windows desktop launcher for Minecraft Java Edition. It is designed to keep launcher and game data local where practical and to avoid unnecessary collection of personal information.

Microsoft authentication

Vesper uses Microsoft's OAuth device authorization flow. Authentication is handled by Microsoft. Vesper does not ask for or store the user's Microsoft password.

The application requests the scopes XboxLive.signin and offline_access. Vesper does not request Microsoft Graph permissions.

Credentials and tokens

Refresh credentials are stored locally using Windows Credential Manager. Access tokens are used in application memory as required for authentication with Microsoft, Xbox and Minecraft services. Vesper does not intentionally transmit these credentials to Kognitiv Systems or a custom analytics server.

Local game data

Launcher configuration, Minecraft files, logs, version metadata, managed Java runtimes, imported instances and game data are stored locally on the user's device as required for launcher functionality.

Updates

Vesper may contact its configured release endpoint to check for new versions. Update packages are cryptographically verified before installation. Release hosting providers may receive ordinary network metadata under their own privacy policies.

Account requirements

Vesper requires legitimate Microsoft/Minecraft authentication. It does not provide a cracked, offline-account or authentication-bypass mode.

Third-party services

Vesper communicates with services operated by Microsoft, Xbox, Mojang/Minecraft and release-hosting infrastructure where needed for authentication, game metadata, legitimate game access and updates. Those services have their own privacy policies.

Integrated Client

Vesper Client stores configuration, HUD layouts, presets and Waypoints locally. It adds no telemetry. Payloads included with the manually installed Launcher are applied to opted-in instances before game launch. Automatic beta updates are not currently promised; Stable 0.4.0 retains its existing channel.

Optional Discord presence

Rich Presence is OFF by default. When enabled, the local Discord application receives generic main-menu/singleplayer/multiplayer activity, an elapsed-time timestamp, optional Minecraft version and Vesper artwork when configured. No world/server names, addresses, coordinates, account names, UUIDs or Waypoints are sent in the activity payload. Discord controls visibility under its own privacy settings.

Provisioning services

Fabric dependencies come from Fabric services, managed Java from Adoptium/Temurin services, and optional mod search/downloads from Modrinth and its download infrastructure. These providers receive normal request metadata and apply their own policies.
